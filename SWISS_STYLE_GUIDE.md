# Swiss Research Style — v5.3

## Palette

### Light mode
- Background: `#F7F5EF`
- Surface: `#ECE9E0`
- Main text: `#111111`
- Secondary text: `#66635D`
- Borders: `#CBC7BC`
- Accent: `#D63230`

### Dark mode
- Background: `#141414`
- Surface: `#1E1E1E`
- Main text: `#F1EFE8`
- Secondary text: `#A7A39A`
- Borders: `#383633`
- Accent: `#FF615E`

## Controls

Three icon buttons are shown in the upper-right corner:

1. **Compact** — reduces vertical spacing and image placeholder height.
2. **Motion** — disables reveal/transitions.
3. **Theme** — switches between Quarto light and dark themes.

## Motion safety

The content is always visible by default. JavaScript activates hidden animation states
only after successful initialization. If JavaScript fails, the content remains visible.

## Sidebar

The Quarto TOC is styled as:

- uppercase Swiss-style section/group titles;
- indented subtitles and technical subsections;
- red active indicator;
- no card-like background.

The same rules apply to Portfolio, CV, Contact and all detailed project pages.
