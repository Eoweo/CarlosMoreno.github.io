# Images

Recommended structure:

```text
assets/images/
├── thesis/
│   ├── platform/
│   ├── monitoring/
│   └── icg/
├── cybathlon/
├── candel/
```

For web use:
- prefer `.webp` or optimized `.jpg`;
- keep large original files outside the website repository;
- use descriptive file names;
- do not publish confidential or identifiable clinical material.
