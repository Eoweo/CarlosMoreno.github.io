# Carpeta `imagenes` — v9.2

Esta carpeta contiene únicamente los recursos visuales que actualmente existen o que el usuario indicó que puede aportar.

## Flujo de trabajo
1. Reemplaza cada archivo vacío por el archivo real.
2. Conserva exactamente el mismo nombre y extensión.
3. No agregues versiones alternativas salvo que también se actualice `IMAGENES_REQUERIDAS.md`.
4. Si un archivo está vacío o no carga, la web mantiene el placeholder.
5. Si carga correctamente, el placeholder desaparece automáticamente.
