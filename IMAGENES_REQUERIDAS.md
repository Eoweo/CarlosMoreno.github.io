## Reglas

1. No renombrar los archivos.
2. Reemplazar el archivo vacío, no crear una ruta alternativa.
3. Mantener `.jpg` para fotografías y `.png` para diagramas, gráficos, renders o capturas.
4. Los elementos técnicos usan `object-fit: contain` para evitar recortes.
5. El retrato principal usa `object-fit: cover`.
6. Si un archivo sigue vacío o es inválido, la web conserva el placeholder descriptivo.
7. Cuando el archivo es una imagen válida, el placeholder se oculta automáticamente.
8. Recomendación: mínimo 1600 px de ancho para imágenes grandes y 1200 px para medianas.
